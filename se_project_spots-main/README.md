# **Spots**

A dynamic web-based photo-sharing platform.

## **Description**

Spots is an intuitive, web-based photo-sharing application where users can upload photos and share them with others. Visitors to a user’s profile can view and like their photos, providing a simple yet interactive social experience. The application is built using a combination of HTML and CSS, with a focus on clean, responsive design.

## **Project Features**

- \*\* HTML, CSS, and JavaScript: Core technologies for structure, style, and functionality.
- \*\* Flexbox & Grid Layouts: Efficient layout management for a seamless user experience.
- \*\* Responsive Design: Optimized for various devices, from desktops to mobile phones, ensuring a consistent and adaptable experience.
- \*\* Dynamic Content Rendering: Cards, modals, and forms are generated dynamically with JavaScript.
- \*\* API Integration: Fetch user data and manage photo cards using an external API.
- \*\* Form Validation: Built-in form validation with dynamic error handling and button state management.
